Features

What is Hinterland?

A browser that adapts to you — fast, private and extensible.

Fast & light

Optimised Chromium core with tab snoozing and memory saver.

Private & secure

Tracker blocking, HTTPS-first, private tabs and granular site permissions.

Extensible

MV3 extensions with a strict security policy and its own Extension SDK.

Reader Mode

Distraction-free reading with colour schemes, typography and column width.

Tab Stash

Save, organise and restore sessions — with JSON backup.

Password manager

Zero-knowledge AES-GCM vault with autofill and generator.
